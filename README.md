# 9-Key Macropad

This is my KiCad design for a 9-key macropad.  
I created the schematic with switches, microcontroller, and OLED, then assigned footprints and made the PCB layout.  

## What I learned
- Adding symbols in KiCad
- Assigning footprints
- Updating PCB from schematic and PCB desigining
- Learning how the PCB works
  
## Files included
- Schematic (.kicad_sch)
- PCB layout (.kicad_pcb)
- Project file (.kicad_pro)
My Experience
This was my first PCB project using KiCad.

At first I had trouble setting up footprints and libraries. After spending time learning KiCad, I was able to create the schematic and PCB layout.

This project helped me understand how components connect together and how a PCB is designed.
